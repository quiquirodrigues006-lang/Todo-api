Todo API - Documentação

API RESTful para gerenciamento de tarefas. Todas as requisições (exceto a geração de token) exigem autenticação via JWT.

Autenticação

Envie o token no cabeçalho das requisições protegidas: Authorization: Bearer <seu_token_jwt>

POST /api/token/

Gera o par de tokens (access e refresh) para um usuário existente.

Body (JSON)

{
  "username": "seu_usuario",
  "password": "sua_senha"
}

POST /api/token/refresh/

Gera um novo token de acesso usando o token de refresh.

Body (JSON)

{
  "refresh": "seu_token_de_refresh_aqui"
}

Tarefas (Tasks)

GET /api/tasks/

Retorna a lista de todas as tarefas pertencentes ao usuário autenticado.

Response (200 OK)

[
  {
    "id": 1,
    "user": "nome_do_usuario",
    "title": "Estudar Django",
    "description": "Revisar serializers e views",
    "status": "PENDING",
    "priority": 3,
    "created_at": "2026-09-12T10:00:00Z",
    "updated_at": "2026-09-12T10:00:00Z"
  }
]

POST /api/tasks/

Cria uma nova tarefa para o usuário autenticado.

Body (JSON)

{
  "title": "Comprar café",
  "description": "Pacote de 500g",
  "status": "PENDING",  // Opções: PENDING, COMPLETED
  "priority": 2         // Opções: 1 (Baixa), 2 (Média), 3 (Alta)
}

GET /api/tasks/<id>/

Retorna os detalhes de uma tarefa específica.

PUT /api/tasks/<id>/

Atualiza integralmente uma tarefa existente. Exige o envio de todos os campos obrigatórios.

PATCH /api/tasks/<id>/

Atualiza parcialmente uma tarefa existente. Você pode enviar apenas os campos que deseja alterar.

Body (JSON) - Exemplo

{
  "status": "COMPLETED"
}

DELETE /api/tasks/<id>/

Remove a tarefa do sistema.

Response

204 No Content (Sem corpo de resposta)
